# SNS Crossover

YouTube・X・Instagram・Threads を **1つのウィンドウに横並びで表示** して、それぞれのタイムラインを同時に流し見できるデスクトップアプリです。

各列の中身は公式サイトそのものなので、API の制限や料金はかかりません。ログインも各列でふつうに行います。

```
┌ SNS Crossover ─ [YouTube] [X] [Instagram] [Threads] ──── ⟳ すべて更新 ┐
│ ● YouTube    ← → ⟳ ⌂ ⤢ │ ● X  …   │ ● Instagram … │ ● Threads … │
│                          │          │               │             │
│  （公式サイトの画面）     │          │               │             │
└──────────────────────────┴──────────┴───────────────┴─────────────┘
```

## できること

- 4つの SNS を横並びで表示（各列で個別にログイン。ログイン状態は次回起動時も保持）
- 上部のボタンで SNS ごとに表示 / 非表示を切り替え
- 各列の見出し: 戻る・進む・再読み込み・ホーム・拡大縮小（50〜150%）
- `⤢` または見出しのダブルクリックで、その列だけ大きく表示
- 「すべて更新」で全列をまとめて再読み込み
- SNS の外へのリンク（ニュース記事など）はふだん使っているブラウザで開く
- 右クリックメニュー（リンクのコピー、ブラウザで開く など）
- 表示する列・倍率・ウィンドウサイズは自動で保存

## 使い方

### 1. 完成したアプリをダウンロードする（おすすめ）

GitHub にプッシュするたびに、GitHub Actions が Windows / Mac / Linux 用のアプリを自動で作ります。

1. リポジトリの **Actions** タブ →「Build」の最新の実行を開く
2. 下の **Artifacts** から自分の OS のものをダウンロード
   - Windows: `sns-crossover-Windows`（中の `.exe` を実行）
   - Mac: `sns-crossover-macOS`（中の `.dmg` を開く）
3. 署名していないアプリなので、初回は警告が出ます
   - Windows:「Windows によって PC が保護されました」→「詳細情報」→「実行」
   - Mac: アプリを右クリック →「開く」（それでも開けない場合は「システム設定 → プライバシーとセキュリティ」から許可）

### 2. ソースから起動する（開発用）

[Node.js](https://nodejs.org/)（v22 以上）を入れてから:

```sh
npm install
npm start
```

自分のパソコン用のインストーラーを作るときは `npm run dist`（`dist/` に出力）。

## SNS を増やす・変える

`src/columns.js` の一覧に追加するだけで列が増えます。

```js
{
  id: 'bluesky',            // 英数字の識別子（ログイン情報の保存先の名前にもなる）
  name: 'Bluesky',          // 見出しに出る名前
  color: '#1185fe',         // 見出しの色
  home: 'https://bsky.app/',
  domains: ['bsky.app'],    // この列の中で開くドメイン
},
```

## 仕組み

- [Electron](https://www.electronjs.org/) 製。各列は独立したブラウザ画面（`WebContentsView`）で、SNS ごとに保存領域を分けています。
- 各 SNS のサイトは別サイトへの埋め込み（iframe）を禁止しているため、Web ページではなくデスクトップアプリにしています。
- 通知・カメラ・位置情報などの許可は求められても許可しません（全画面表示とコピーのみ許可）。

| ファイル | 役割 |
|---|---|
| `src/columns.js` | 表示する SNS の一覧 |
| `src/main.js` | ウィンドウと各列の作成、リンクの振り分け、設定の保存 |
| `src/index.html` / `renderer.js` / `styles.css` | 上部バーと各列の見出し |
| `src/preload.js` | 見出しとメイン処理の橋渡し |

## 注意

- **Google（YouTube）のログイン**: Google はアプリ内ブラウザからのログインを拒否することがあります。このアプリは通常の Chrome として振る舞うようにしていますが、それでも「安全でないブラウザ」と表示された場合は、YouTube はログインなしでも閲覧できます。
- 列の幅が狭いと、サイトによってはスマホ風のレイアウトになります。見づらいときは `−` で縮小するか `⤢` で大きく表示してください。
- 各 SNS の利用規約に従って、個人の閲覧用として使ってください。
